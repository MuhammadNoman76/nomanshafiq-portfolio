# KINETIC: reference study and design system

## Reference study

The user asked to research exceptional animated 3D websites rather than restyle the rejected previous design. The live reference pages and visual examples were reviewed through web research; the external interactive sites could not be run inside the network-restricted local browser.

- **Lusion:** https://lusion.co/ . A reference for putting an original real-time visual at the center of an editorial composition. The studio describes its work as 3D and interactive web experiences. Its v3 site won CSS Design Awards' 2023 Website of the Year: https://www.cssdesignawards.com/blog/2023-website-of-the-year-winners/394/
- **Igloo:** https://www.igloo.inc/ . A reference for one memorable 3D object and an immersive visual world. Awwwards' own announcement names it the 2024 Site of the Year and Developer Site of the Year: https://www.linkedin.com/posts/awwwards_we-are-thrilled-to-announce-that-the-winners-activity-7307431367728861187-ED07
- **Bruno Simon:** https://bruno-simon.com/ . A reference for interaction as an expression of personality and craft, rather than a decorative layer.

These are references, not copied assets. No code, models, logos, branding, or site screenshots from them are bundled in this project. There is no universal objective 'most beautiful website' ranking.

## UI/UX Pro Max

Requested skill: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

Applied from its read instructions: accessibility before decoration; 44px controls; semantic links and buttons; no emoji structural icons; visible focus; no hover-only critical action; keyboard alternatives to dragging; meaningful motion; reduced-motion behavior; responsive layout; reserved dimensions; local asset delivery; no invisible hero waiting for JavaScript.

The external skill's Python search CLI was **not runnable in this environment**, because the repository and its full dataset could not be downloaded. No database match or generated CLI design-system result is claimed. The authored design system below uses the inspected skill priorities as general guidance and the explicit reference study, not fabricated search output.

## Original direction

'Curiosity, made real.' Noman's identity is presented through the relationship between human curiosity and engineered products. A continuous chrome knot is a recognizable visual signature. It can become a loop or a three-dimensional wave: connected thinking, flow, and a different perspective.

### Palette

- Paper: #e9edf0 (cool, restrained gallery ground)
- Ink: #191c20
- Secondary type: #586067
- Dividers: #c7cdd2
- Accent: #f05b37 (selective punctuation and the approach section)
- Cobalt: #2448df (sculptural contrast)
- Project grounds: powder blue, peach, lime, rose, ice

### Typography

Native Arial / Helvetica, with Georgia italic used only for the human emphasis in hero and contact. Monospace micro-labels supply a precise technical counterpoint. No font files are bundled or redistributed, and no network font download is needed.

### Composition

Wide margins, oversized text, one dimensional object, generous negative space, asymmetric project posters, a compact project index, a large editorial statement, and a restrained resume timeline. No generic icon-card grid, skill-percentage bars, fabricated awards, or fake product dashboards.

### Motion contract

Transforms and camera movement communicate an interaction. User rotation and morph controls work independently of ambient movement. Native scrolling is preserved. Animation stops out of view or when the tab is hidden. Reduced-motion users see immediate state changes and static thumbnail artwork. If WebGL is unavailable, shape buttons select three locally rendered views rather than becoming dead controls.

### Rendering

The original engine builds real mesh positions, smooth normals, three morph targets, index buffers, a depth-buffered WebGL scene, and a procedural studio reflection shader. It does not download a 3D model or use a stock image. Local artwork was rendered from the same geometry and shader using headless native OpenGL for the browser fallback and project plates.
