# SEO launch checklist

## Before launch

- Confirm `NEXT_PUBLIC_SITE_URL` is the exact canonical production domain.
- Confirm every public route returns HTTP 200.
- Keep HTTPS enabled and redirect HTTP to HTTPS.
- Keep only one canonical hostname, for example `www.thenoman.online`.
- Verify the generated `/robots.txt` and `/sitemap.xml` after deployment.
- Verify `/opengraph-image` loads publicly.
- Test the homepage and project pages with Google Rich Results Test.
- Test structured data with Schema.org Validator.
- Add the production site to Google Search Console and Bing Webmaster Tools.
- Submit the sitemap.

## Content strategy

The site is intentionally written around natural search intent rather than repeated keywords. Main topics are:

- Muhammad Noman AI Engineer
- AI Engineer in Karachi / Pakistan
- Agentic AI Engineer
- AI Agent Developer
- LLM Engineer
- LangChain / LangGraph developer
- RAG and LLM applications
- Full-stack AI developer
- Azure AI engineer
- Next.js and Python AI product engineering

The `/work/*` routes provide unique indexable content for individual projects. Expand those pages over time with architecture diagrams, technical decisions, screenshots, measurable outcomes, and links from reputable external sites.

## Highest-impact ongoing work

1. Publish genuinely useful technical case studies.
2. Earn relevant links from GitHub, LinkedIn, product websites, conference/workshop pages, and technical communities.
3. Keep the site fast and stable.
4. Update project pages when meaningful work changes.
5. Use Search Console query data to improve titles and page copy based on real impressions.
